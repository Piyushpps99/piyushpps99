🔐 Introduction to Cybersecurity

Cybersecurity is the practice of protecting digital systems, networks, devices, and data from unauthorized access, theft, or damage.

⭐ CIA TRIAD
Confidentiality Keeping sensitive data private from intruders.
Integrity Ensuring information is not altered or corrupted.
Availability Guaranteeing systems remain accessible to authorized users.

1️⃣ Fundamental Definitions & Relationship

In cybersecurity, Threat, Vulnerability, and Attack are important concepts.

[ Threat Agent ] ↓ Exploits ↓ [ Vulnerability ] ↓ Triggers ↓ [ Attack ] ↓ [ Harm / Impact ]
Term Definition Example
Vulnerability A weakness or loophole in a system's design, implementation, or operational controls. Unpatched software, weak passwords
Cyber Threat Any potential incident or actor capable of exploiting a vulnerability. Hackers, ransomware campaigns
Cyber Attack The actual deliberate action taken by an attacker to exploit a vulnerability. SQL Injection, phishing
Risk = Threat × Vulnerability × Impact

2️⃣ Cyber Attack Types

🎣 Phishing

Phishing is a social engineering attack where an attacker impersonates a trustworthy entity through email, SMS, or web pages to steal sensitive information.

[ Attacker ] ↓ Spoofed Email ↓ [ Victim ] ↓ Fake Link ↓ [ Phishing Page ] ↓ Credentials Stolen

Types of Phishing

Spear Phishing Targeted attack against a specific person or organization.
Whaling Phishing aimed at high-profile executives.
Vishing Phishing conducted through voice calls.
Smishing Phishing conducted through SMS.
Clone Phishing Copying a legitimate email and replacing it with malicious links.

🦠 Malware

Malware is software intentionally designed to cause damage, disrupt functionality, or gain unauthorized access.

Virus Requires a host file and human execution.
Worm Self-replicates and spreads through networks.
Trojan Horse Looks like legitimate software but contains a malicious payload.
Ransomware Encrypts files and demands payment.
Spyware / Keylogger Secretly monitors user activity and keystrokes.

💉 SQL Injection

SQL Injection is an application-layer attack in which malicious SQL commands are inserted into user input fields. 

SELECT * FROM Users
WHERE username = 'USER_INPUT'
AND password = 'PASSWORD_INPUT';
Example: 
admin' OR '1'='1

🛡️ SQL Injection Prevention

  • Prepared Statements
  • Parameterized Queries
  • Input Validation
  • Web Application Firewall (WAF)

4️⃣ Digital Forensics

Digital Forensics is the process of identifying, preserving, extracting, analyzing, and presenting digital evidence.

Identification ↓ Preservation ↓ Acquisition ↓ Analysis ↓ Reporting
1. Identification Locate potential digital evidence.
2. Preservation Protect evidence from alteration.
3. Acquisition Create a forensic image of the media.
4. Analysis Examine files, logs and system artifacts.
5. Reporting Document findings in a technical report.

5️⃣ Cryptography

Cryptography is the science and practice of securing communication and data against unauthorized access.

🔑 Four Security Goals

Confidentiality Only authorized entities can access data.
Integrity Data must not be altered.
Authentication Verifies identity.
Non-Repudiation Prevents denial of an action.

Symmetric Encryption

A single shared secret key is used for both encryption and decryption.

Total Keys = N(N − 1) / 2

Asymmetric Encryption

Asymmetric cryptography uses two mathematically related keys: a Public Key and a Private Key.

Public Key Shared publicly.
Private Key Kept secret by the owner.

Digital Signature

Message ↓ Hash Function ↓ Hash ↓ Encrypt using Private Key ↓ Digital Signature
Verification: If Hash 1 = Hash 2 → Signature is Valid. If Hash 1 ≠ Hash 2 → Signature is Invalid.

6️⃣ Web Security

Web Security involves protecting web applications, servers and HTTP/HTTPS communications against attacks.

Cross-Site Scripting (XSS) Injection of malicious scripts into web applications.
CSRF Tricks an authenticated browser into sending an unwanted request.
HTTPS/TLS Protects web traffic using encryption.
Session Hijacking Attackers capture or guess valid session identifiers.

7️⃣ Social Engineering

Social Engineering manipulates people into revealing confidential information or performing unsafe actions.

Phishing Fraudulent communication to steal information.
Pretexting Creating a fake scenario to persuade a victim.
Baiting Using an attractive object such as an infected USB.
Tailgating Following an authorized person into a restricted area.

🛡️ Defense

  • Security Awareness Training
  • Verification Procedures
  • Multi-Factor Authentication (MFA)
  • Regular Security Training
