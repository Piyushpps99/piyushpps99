1 Introduction to C++

C++ is a powerful general-purpose programming language created by Bjarne Stroustrup in 1979 at Bell Labs. He wanted to add object-oriented features to the C language. The name C++ means “C incremented by 1” (the ++ operator).

C++ is both a procedural language (like C – step by step instructions) and an object-oriented language (classes, objects, inheritance). This combination makes it extremely flexible and fast.

Why learn C++?

  • Extremely high performance (games, operating systems, browsers, high-frequency trading)
  • Foundation for many other languages (Java, C#, Python internals)
  • Very rich Standard Template Library (STL)
  • Used in competitive programming (Codeforces, LeetCode hard problems)
  • Gives you deep understanding of how computers really work (memory, pointers)

Key Features

  • Compiled language (converted to machine code before running)
  • Statically typed (you must declare type of every variable)
  • Supports OOP, templates, exceptions, lambda functions
  • Manual memory management + modern RAII (Resource Acquisition Is Initialization)
  • Zero-cost abstractions (you pay only for what you use)
Deep Understanding: When you write C++ code, the compiler (g++ or clang++) converts it into machine code that the CPU can execute directly. That is why C++ programs run much faster than Python or JavaScript (which are interpreted or use virtual machines).

First Program – Hello World (Detailed Explanation)

C++ hello.cpp 
#include <iostream>   // This brings input/output tools (cout, cin, endl)
using namespace std;    // Allows us to write cout instead of std::cout

int main() {            // main() is the starting point of every C++ program
    cout << "Hello, World!" << endl;   // print text and go to next line
    return 0;           // return 0 means program finished successfully
}
Hello, World!

Line-by-line meaning:

  • #include <iostream> → We are telling the compiler “I need the input-output library”.
  • using namespace std; → Without this we must write std::cout every time.
  • int main() → Every C++ program must have a main function. Execution always starts here.
  • cout << ... → “cout” means character output. The << operator sends data to the screen.
  • endl → Ends the current line (same as \n but also flushes the buffer).
  • return 0; → Tells the operating system that the program ended without error.
How to run:
1. Save the file as hello.cpp
2. Open terminal and type: g++ hello.cpp -o hello
3. Then run: ./hello (on Windows: hello.exe)

3 Control Structures (Making Decisions & Repeating)

Programs need to make decisions and repeat tasks. These are called control structures.

3.1 if – else if – else (Decision Making)

The computer checks conditions from top to bottom and runs the first true block.

C++
#include <iostream>
using namespace std;

int main() {
    int marks = 85;

    if (marks >= 90) {
        cout << "Grade A – Excellent!";
    } else if (marks >= 75) {
        cout << "Grade B – Very Good";
    } else if (marks >= 50) {
        cout << "Grade C – Pass";
    } else {
        cout << "Fail – Need more practice";
    }
    return 0;

Grade B – Very Good

3.2 switch (Multiple Choices)

switch is useful when you have many exact value matches (like menu options).

C++
int day = 3;
switch (day) {
    case 1: cout << "Monday"; break;
    case 2: cout << "Tuesday"; break;
    case 3: cout << "Wednesday"; break;
    case 4: cout << "Thursday"; break;
    case 5: cout << "Friday"; break;
    default: cout << "Weekend or Invalid";
}
Wednesday
Remember: Always put break; after each case, otherwise the code will “fall through” to the next cases.

Pass by Value vs Pass by Reference (Very Important Concept)

Pass by Value: Function gets a copy of the variable. Changes inside function do not affect original.

Pass by Reference: Function gets the actual variable (using &). Changes affect the original.

C++
void changeValue(int x) {   // pass by value (copy)
    x = 100;
}

void changeRef(int &x) {    // pass by reference (real variable)
    x = 100;
}

int main() {
    int a = 10;
    changeValue(a);
    cout << a << endl;   // still 10 (copy was changed)

    changeRef(a);
    cout << a << endl;   // now 100 (original changed)
}
10 100
When to use reference (&):
• When you want the function to modify the original variable
• When passing large objects (vectors, strings) to avoid expensive copying

Default Arguments & Function Overloading

C++
// Default argument – if not provided, uses 10
void print(int a, int b = 10) {
    cout << a << " " << b << endl;
}

// Function Overloading – same name, different parameter types or count
int multiply(int a, int b) { return a * b; }
double multiply(double a, double b) { return a * b; }
int multiply(int a, int b, int c) { return a * b * c; }

5 Arrays & Strings

5.1 Arrays – Fixed Size Collection

An array stores multiple values of the same type in continuous memory locations. Index always starts from 0.

C++
#include <iostream>
using namespace std;

int main() {
    int arr[5] = {10, 20, 30, 40, 50};

    // Access individual elements
    cout << arr[0] << endl;   // 10 (first element)
    cout << arr[2] << endl;   // 30 (third element)

    // Traverse (visit every element)
    for (int i = 0; i < 5; i++) {
        cout << arr[i] << " ";
    }
    cout << endl;

    // Calculate size
    cout << "Size: " << sizeof(arr)/sizeof(arr[0]) << endl;
    return 0;
}
10 30 10 20 30 40 50 Size: 5
Warning: Accessing index outside the array size (e.g. arr[10]) causes undefined behavior – program may crash or give wrong results. Always stay within bounds.

6 Pointers (Very Important & Powerful)

A pointer is a special variable that stores the memory address of another variable instead of storing a normal value.

Why Pointers Matter:
• They allow direct memory access and manipulation
• Essential for dynamic memory, arrays, linked lists, trees, graphs
• Used heavily in system programming, game engines, and high-performance code
C++
#include <iostream>
using namespace std;

int main() {
    int x = 42;
    int *ptr = &x;   // ptr stores the address of x

    cout << "Value of x: " << x << endl;
    cout << "Address of x: " << &x << endl;
    cout << "Value stored in ptr: " << ptr << endl;
    cout << "Value pointed by ptr: " << *ptr << endl;  // dereference

    *ptr = 100;      // change the value of x through the pointer
    cout << "New value of x: " << x << endl;
    return 0;
}
Value of x: 42 Address of x: 0x7ffd... (some memory address) Value stored in ptr: 0x7ffd... (same address) Value pointed by ptr: 42 New value of x: 100

Dynamic Memory Allocation (new & delete)

Sometimes we don’t know the size of data at compile time. We use heap memory with new and must free it with delete.

C++
int *p = new int;     // allocate memory for one integer on heap
*p = 50;
cout << *p << endl;

delete p;             // free the memory (very important!)

// Dynamic array
int *arr = new int[5];
for (int i = 0; i < 5; i++) arr[i] = i * 10;
delete[] arr;         // free the entire array
Memory Leak Warning: If you use new but forget delete, the memory stays allocated forever until the program ends. In long-running programs this can crash the system. Prefer modern smart pointers (unique_ptr, shared_ptr).

7 Object-Oriented Programming (OOP)

OOP is a way of designing programs using “objects” that contain both data and functions. The four main pillars are:

  1. Encapsulation – Bundling data and methods together + hiding internal details
  2. Abstraction – Showing only essential features, hiding complexity
  3. Inheritance – Creating new classes from existing ones
  4. Polymorphism – Same interface, different behaviors

7.1 Class & Object

C++
#include <iostream>
using namespace std;

class Student {
private:                 // Encapsulation – data is hidden
    string name;
    int age;

public:
    // Constructor – special function that runs when object is created
    Student(string n, int a) {
        name = n;
        age = a;
    }

    void display() {
        cout << name << " is " << age << " years old." << endl;
    }
};

int main() {
    Student s1("Rahul", 20);   // Object creation
    s1.display();
    return 0;
}
Rahul is 20 years old.

Inheritance allows a class (child) to reuse the properties and methods of another class (parent).

C++

7.3 Polymorphism

Compile-time Polymorphism: Function overloading / Operator overloading
Runtime Polymorphism: Virtual functions + override

C++
class Shape {
public:
    virtual void draw() {          // virtual enables runtime polymorphism
        cout << "Drawing Shape" << endl;
    }
};

10.1 Time Complexity (Big O) – Must Master

Time complexity tells us how the running time of an algorithm grows as the input size (n) grows. We care about the worst-case scenario.

Complexity Name Example When n = 1 million
O(1)ConstantAccess array[i]Instant
O(log n)LogarithmicBinary Search~20 steps
O(n)LinearSingle loop1 million steps
O(n log n)LinearithmicMerge Sort, Heap Sort~20 million steps
O(n²)QuadraticBubble / Selection / Insertion Sort1 trillion steps (too slow)
O(2ⁿ)ExponentialNaive recursive FibonacciImpossible
Deep Understanding: In competitive programming, for n ≤ 10⁵ you can usually afford O(n log n). For n ≤ 10⁶ you need O(n) or better. O(n²) is only acceptable when n ≤ 1000–2000.

10.2 Searching Algorithms

Linear Search – O(n)

Check every element one by one from start to end.

C++
int linearSearch(int arr[], int n, int key) {
    for (int i = 0; i < n; i++) {
        if (arr[i] == key) return i;   // found at index i
    }
    return -1;  // not found
}

Binary Search – O(log n) (Array must be sorted)

Repeatedly divide the search space in half. Extremely efficient.

C++
int binarySearch(int arr[], int n, int key) {
    int low = 0, high = n - 1;
    while (low <= high) {
        int mid = low + (high - low) / 2;   // prevents overflow
        if (arr[mid] == key) return mid;
        else if (arr[mid] < key) low = mid + 1;
        else high = mid - 1;
    }
    return -1;
}
Why mid = low + (high - low)/2 ?
Writing (low + high)/2 can cause integer overflow when low and high are very large. The safer formula avoids that.

10.3 Sorting Algorithms (Deep)

Bubble Sort – O(n²)

Repeatedly swap adjacent elements if they are in wrong order. Simple but slow.

C++
void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n-1; i++) {
        for (int j = 0; j < n-i-1; j++) {
            if (arr[j] > arr[j+1])
                swap(arr[j], arr[j+1]);
        }
    }
}

Selection Sort – O(n²)

Find the minimum element and put it at the beginning. Repeat for remaining array.

C++
void selectionSort(int arr[], int n) {
    for (int i = 0; i < n-1; i++) {
        int minIdx = i;
        for (int j = i+1; j < n; j++) {
            if (arr[j] < arr[minIdx]) minIdx = j;
        }
        swap(arr[i], arr[minIdx]);
    }
}

Insertion Sort – O(n²) best for nearly sorted data

C++
void insertionSort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j+1] = arr[j];
            j--;
        }
        arr[j+1] = key;
    }
}

Merge Sort – O(n log n) – Stable & Guaranteed

Divide the array into two halves, sort each half recursively, then merge the sorted halves.

C++
void merge(int arr[], int l, int mid, int r) {
    int n1 = mid - l + 1;
    int n2 = r - mid;
    int L[n1], R[n2];
    for (int i = 0; i < n1; i++) L[i] = arr[l + i];
    for (int j = 0; j < n2; j++) R[j] = arr[mid + 1 + j];

    int i = 0, j = 0, k = l;
    while (i < n1 && j < n2) {
        if (L[i] <= R[j]) arr[k++] = L[i++];
        else arr[k++] = R[j++];
    }
    while (i < n1) arr[k++] = L[i++];
    while (j < n2) arr[k++] = R[j++];
}

void mergeSort(int arr[], int l, int r) {
    if (l < r) {
        int mid = l + (r - l) / 2;
        mergeSort(arr, l, mid);
        mergeSort(arr, mid + 1, r);
        merge(arr, l, mid, r);
    }
}

10.4 Linked List (Deep Theory)

A linked list is a dynamic data structure where each element (node) contains data and a pointer to the next node. Unlike arrays, size can grow or shrink easily, but random access is slower (O(n)).

C++
#include <iostream>
using namespace std;

struct Node {
    int data;
    Node* next;
    Node(int val) : data(val), next(nullptr) {}
};

void printList(Node* head) {
    while (head != nullptr) {
        cout << head->data << " → ";
        head = head->next;
    }
    cout << "NULL" << endl;
}

int main() {
    Node* head = new Node(10);
    head->next = new Node(20);
    head->next->next = new Node(30);

    printList(head);
    // Always free memory in real programs
    return 0;
}
10 → 20 → 30 → NULL

10.8 Recursion Essentials

Recursion is when a function calls itself. Every recursive function needs:

  • Base case – condition to stop
  • Recursive case – function calls itself with smaller input
C++
// Factorial
int fact(int n) {
    if (n <= 1) return 1;          // base case
    return n * fact(n - 1);        // recursive case
}

// Fibonacci (naive – exponential time)
int fib(int n) {
    if (n <= 1) return n;
    return fib(n-1) + fib(n-2);
}

11 Graphs (Deep Theory + Code)

A graph is a collection of nodes (vertices) connected by edges. Used in social networks, maps, web pages, recommendation systems, etc.

Two Common Representations

  • Adjacency Matrix – 2D array (good for dense graphs)
  • Adjacency List – vector of vectors (preferred for most problems)
C++
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n = 5; // number of nodes (0 to 4)
    vector<vector<int>> adj(n);

    // Add undirected edges
    adj[0].push_back(1);
    adj[1].push_back(0);
    adj[1].push_back(2);
    adj[2].push_back(1);
    adj[2].push_back(3);
    adj[3].push_back(2);

    // Print adjacency list
    for (int i = 0; i < n; i++) {
        cout << i << ": ";
        for (int neighbor : adj[i]) cout << neighbor << " ";
        cout << endl;
    }
}

BFS (Breadth-First Search) – Level Order

Uses a queue. Explores all neighbors at current depth before going deeper. Useful for shortest path in unweighted graphs.

C++
void bfs(int start, vector<vector<int>>& adj, int n) {
    vector<bool> visited(n, false);
    queue<int> q;
    q.push(start);
    visited[start] = true;

    while (!q.empty()) {
        int node = q.front();
        q.pop();
        cout << node << " ";

        for (int neighbor : adj[node]) {
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                q.push(neighbor);
            }
        }
    }
}

DFS (Depth-First Search)

Uses recursion or stack. Goes as deep as possible along one path before backtracking.

C++
void dfs(int node, vector<vector<int>>& adj, vector<bool>& visited) {
    visited[node] = true;
    cout << node << " ";

    for (int neighbor : adj[node]) {
        if (!visited[neighbor]) {
            dfs(neighbor, adj, visited);
        }
    }
}

12 Dynamic Programming (Deep Theory)

Dynamic Programming (DP) is an optimization technique that solves complex problems by breaking them into smaller overlapping subproblems and storing their results to avoid recomputation.

Two main approaches:
1. Top-Down (Memoization) – Write recursive solution + store results in a table
2. Bottom-Up (Tabulation) – Solve smallest subproblems first and build up to the answer

Classic Example: Fibonacci with DP

C++
// Bottom-up DP – O(n) time, O(n) space
int fibDP(int n) {
    if (n <= 1) return n;
    vector<int> dp(n+1);
    dp[0] = 0;
    dp[1] = 1;
    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2];
    }
    return dp[n];
}

// Space optimized version – O(1) space
int fibOptimized(int n) {
    if (n <= 1) return n;
    int prev2 = 0, prev1 = 1;
    for (int i = 2; i <= n; i++) {
        int curr = prev1 + prev2;
        prev2 = prev1;
        prev1 = curr;
    }
    return prev1;
}

0/1 Knapsack (Classic DP Problem)

You have items with weights and values. Pick a subset that maximizes value without exceeding capacity.

C++
int knapsack(int W, vector<int>& wt, vector<int>& val, int n) {
    vector<vector<int>> dp(n+1, vector<int>(W+1, 0));

    for (int i = 1; i <= n; i++) {
        for (int w = 1; w <= W; w++) {
            if (wt[i-1] <= w)
                dp[i][w] = max(val[i-1] + dp[i-1][w - wt[i-1]], dp[i-1][w]);
            else
                dp[i][w] = dp[i-1][w];
        }
    }
    return dp[n][W];
}
