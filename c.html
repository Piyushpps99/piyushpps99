UNIT I — Basics of Programming & Basics of C

1.1 Approaches to Problem Solving

Problem solving in programming means converting a real-world problem into a working computer program. The systematic approach consists of:

  1. Understanding the Problem — Identify inputs, outputs, constraints and special cases.
  2. Analyzing the Problem — Break into smaller sub-problems (divide and conquer).
  3. Designing the Solution — Choose data structures and algorithms; draw flowcharts or write pseudocode.
  4. Coding — Translate the design into C.
  5. Testing & Debugging — Run with various test cases; fix syntax, logical and runtime errors.
  6. Documentation & Maintenance — Write comments, manuals and keep the program up-to-date.

Common Approaches: Top-Down, Bottom-Up, Modular Programming.

1.2 High-level Programming Languages

High-level languages (C, C++, Java, Python, etc.) are closer to human language than machine code. Advantages:

  • Easier to read, write and understand
  • Portability across machines
  • Built-in functions and libraries
  • Support for structured programming
  • Abstraction (no direct register management, except via pointers in C)

1.3 Algorithm and Flowchart

An algorithm is a finite sequence of well-defined steps that is finite, definite, effective and produces output.

Example Algorithm — Largest of three numbers
Step 1: Start
Step 2: Read three numbers A, B, C
Step 3: If A > B then
            If A > C then Largest = A
            Else Largest = C
        Else
            If B > C then Largest = B
            Else Largest = C
Step 4: Print Largest
Step 5: Stop

Flowchart symbols: Oval (Start/Stop), Parallelogram (I/O), Rectangle (Process), Diamond (Decision), Arrows (Flow), Circle (Connector).

1.4 Structured Programming

Uses three basic control structures: Sequence, Selection (if-else, switch), Iteration (loops). Discourages unrestricted goto. Benefits: easier debugging, modular design, better readability, reusable functions.

1.5 History of C & Salient Features

C was developed by Dennis Ritchie at Bell Laboratories in 1972. Evolved from B (Ken Thompson). Designed for writing UNIX. Standards: ANSI C (1989), ISO C, C99, C11, C17, C23.

Salient Features:

  • Simple & Efficient — small keyword set, close to hardware, fast
  • Portable — little or no change across platforms
  • Structured — functions, blocks, modular programming
  • Mid-level language — high-level + low-level features (pointers, bit manipulation)
  • Rich standard library
  • Extensible — user can add functions/libraries
  • Pointer support & Recursion

1.12 Operators and Expressions

  • Arithmetic: + − * / %
  • Relational: == != < > <= >=
  • Logical: && || !
  • Assignment: = += −= *= /= %=
  • Increment/Decrement: ++ −−
  • Bitwise: & | ^ ~ << >>
  • Ternary: condition ? expr1 : expr2
  • Special: sizeof, &, *, comma
#include <stdio.h>
int main() {
    int a = 10, b = 3, c;
    c = a + b * 2;               /* * first → 16 */
    printf("c = %d\n", c);
    printf("a > b : %d\n", a > b);
    int max = (a > b) ? a : b;
    printf("max = %d\n", max);
    a += 5;
    printf("a after += 5 : %d\n", a);
    return 0;
}
Output
c = 16
a > b : 1
max = 10
a after += 5 : 15
UNIT II — Conditional Execution, Loops & Functions

2.1 Conditional Statements — if, if-else, nested if-else

if (condition) {
    // true block
} else {
    // false block
}
#include <stdio.h>
int main() {
    int marks;
    printf("Enter marks: ");
    scanf("%d", &marks);
    if (marks >= 90)      printf("Grade: A+\n");
    else if (marks >= 80) printf("Grade: A\n");
    else if (marks >= 70) printf("Grade: B\n");
    else if (marks >= 60) printf("Grade: C\n");
    else if (marks >= 40) printf("Grade: D\n");
    else                  printf("Grade: F (Fail)\n");
    return 0;
}
Sample Output (input 85)
Grade: A

2.2 Switch Statement

switch (expression) {
    case constant1:
        statements;
        break;
    case constant2:
        statements;
        break;
    default:
        statements;
}

Restrictions: Expression must be integer type; case labels must be unique constants. break prevents fall-through.

#include <stdio.h>
int main() {
    int choice;
    printf("1.Add  2.Subtract  3.Multiply  4.Exit\nEnter choice: ");
    scanf("%d", &choice);
    switch (choice) {
        case 1: printf("Addition selected\n"); break;
        case 2: printf("Subtraction selected\n"); break;
        case 3: printf("Multiplication selected\n"); break;
        case 4: printf("Exiting...\n"); break;
        default: printf("Invalid choice\n");
    }
    return 0;
}

2.3 Loops and Iteration

for loop

for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}
/* Output: 1 2 3 4 5 */

while loop (entry-controlled)

int i = 1;
while (i <= 5) {
    printf("%d ", i);
    i++;
}

do-while loop (exit-controlled — runs at least once)

int i = 1;
do {
    printf("%d ", i);
    i++;
} while (i <= 5);

2.4 Nested Loops, break & continue

#include <stdio.h>
int main() {
    for (int i = 1; i <= 3; i++) {
        for (int j = 1; j <= 3; j++) {
            printf("%d\t", i * j);
        }
        printf("\n");
    }
    return 0;
}
Output
1       2       3
2       4       6
3       6       9

break — exits the innermost loop/switch.
continue — skips rest of current iteration.

for (int i = 1; i <= 10; i++) {
    if (i == 5) continue;   /* skip 5 */
    if (i == 8) break;      /* stop at 8 */
    printf("%d ", i);
}
/* Output: 1 2 3 4 6 7 */

2.5 Functions — Types, Declaration, Definition

A function is a self-contained block that performs a specific task. Benefits: modularity, reusability, easier debugging.

Categories: No args/no return · Args/no return · No args/return · Args + return

#include <stdio.h>

/* Prototype */
int add(int x, int y);

int main() {
    int a = 10, b = 20, sum;
    sum = add(a, b);
    printf("Sum = %d\n", sum);
    return 0;
}

/* Definition */
int add(int x, int y) {
    return x + y;
}
Output
Sum = 30

2.6 Passing Arguments & Return Values

Call by Value (default) — copy is passed; original unchanged.

void swap(int x, int y) {   /* receives copies */
    int temp = x; x = y; y = temp;
}
/* swap(a, b); → a and b remain unchanged */

Call by Reference — address is passed using pointers; original can be modified.

void swap(int *x, int *y) {
    int temp = *x; *x = *y; *y = temp;
}
/* Call: swap(&a, &b); → a and b are swapped */

2.7 Recursive Functions

A function that calls itself. Must have a base case to terminate.

#include <stdio.h>

long factorial(int n) {
    if (n == 0 || n == 1)      /* base case */
        return 1;
    else
        return n * factorial(n - 1);
}

int main() {
    int num = 5;
    printf("Factorial of %d = %ld\n", num, factorial(num));
    return 0;
}
Output
Factorial of 5 = 120
Note
Deep recursion can cause stack overflow. Some problems (tree traversal, Tower of Hanoi) are naturally recursive.
UNIT III — Arrays, Pointers & Strings

3.1 Arrays

An array is a collection of elements of the same data type stored in contiguous memory. Index starts from 0.

int marks[5];                          /* uninitialized */
int nums[5] = {10, 20, 30, 40, 50};    /* initialization */
int vals[] = {1, 2, 3};                /* size inferred = 3 */
nums[0] = 100;
printf("%d", nums[2]);                 /* 30 */
#include <stdio.h>
int main() {
    int arr[5] = {2, 4, 6, 8, 10};
    int sum = 0;
    for (int i = 0; i < 5; i++)
        sum += arr[i];
    printf("Sum = %d\n", sum);
    return 0;
}
/* Output: Sum = 30 */

Two-dimensional Arrays

int matrix[3][4];
int m[2][3] = {{1,2,3}, {4,5,6}};
/* Access: m[1][2] → 6 */
for (int i = 0; i < 2; i++) {
    for (int j = 0; j < 3; j++)
        printf("%d ", m[i][j]);
    printf("\n");
}

3.2 Pointers

A pointer stores the memory address of another variable.

int x = 25;
int *p;            /* pointer to int */
p = &x;            /* p holds address of x */

printf("Value of x   = %d\n", x);
printf("Address of x = %p\n", (void*)&x);
printf("Value of p   = %p\n", (void*)p);
printf("Value at p   = %d\n", *p);   /* 25 */

Pointer Arithmetic

int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;
printf("%d\n", *p);     /* 10 */
p++;
printf("%d\n", *p);     /* 20 */
printf("%d\n", *(p+2)); /* 40 */

Pointer to Pointer / Array of Pointers / Function Pointers

int x = 10;
int *p = &x;
int **pp = &p;
printf("%d\n", **pp);   /* 10 */

int a = 1, b = 2, c = 3;
int *ptr[3] = {&a, &b, &c};
printf("%d\n", *ptr[1]); /* 2 */

int add(int a, int b) { return a + b; }
int (*fp)(int, int) = add;
printf("Result = %d\n", fp(5, 3));  /* 8 */

3.3 Strings

A string is a character array terminated by '\0'.

char str1[] = "Hello";           /* size 6 (includes \0) */
char str2[10] = "World";
char str3[] = {'C', 'o', 'd', 'e', '\0'};
printf("%c\n", str1[1]);         /* e */
printf("%s\n", str1);            /* Hello */

Common string functions (string.h):

  • strlen(s) — length excluding '\0'
  • strcpy(dest, src) / strncpy
  • strcat(dest, src)
  • strcmp(s1, s2) — 0 if equal
  • strchr, strstr
#include <stdio.h>
#include <string.h>
int main() {
    char s1[50] = "Hello";
    char s2[] = " World";
    strcat(s1, s2);
    printf("Concatenated: %s\n", s1);
    printf("Length: %zu\n", strlen(s1));
    printf("Compare: %d\n", strcmp("abc", "abd"));
    return 0;
}
Output
Concatenated: Hello World
Length: 11
Compare: -1

4.1 Structures

A structure groups variables of different data types under a single name.

struct Student {
    int roll;
    char name[30];
    float marks;
};

struct Student s1;
struct Student s2 = {101, "Riya", 92.5};

s1.roll = 102;
strcpy(s1.name, "Amit");
s1.marks = 88.0;

printf("%d %s %.1f\n", s2.roll, s2.name, s2.marks);

Array of Structures & Nested Structures

struct Student class[50];
class[0].roll = 1;
strcpy(class[0].name, "First");

struct Date { int day, month, year; };
struct Employee {
    int id;
    char name[30];
    struct Date joinDate;
};
struct Employee e;
e.joinDate.day = 15;

Pointers to Structure

struct Student *ptr = &s2;
printf("%s\n", ptr->name);   /* arrow operator */
/* equivalent to (*ptr).name */

4.2 Unions

All members share the same memory. Size = size of largest member. Only one member holds a value at a time.

union Data {
    int i;
    float f;
    char str[20];
};
union Data d;
d.i = 10;
printf("%d\n", d.i);     /* 10 */
d.f = 3.14;              /* overwrites memory */
printf("%f\n", d.f);     /* 3.14 */

4.3 Enumerated Data Types

enum Weekday { MON, TUE, WED, THU, FRI, SAT, SUN };
/* MON=0, TUE=1, ... by default */
enum Weekday today = WED;
printf("%d\n", today);   /* 2 */

UNIT V — Dynamic Memory, File Handling & Graphics

5.1 Dynamic Memory Allocation

Memory is requested from the heap at runtime using functions from <stdlib.h>.

  • malloc — allocates uninitialized block
  • calloc — allocates and zeroes the block
  • realloc — resizes previously allocated block
  • free — releases memory (always free to avoid leaks)
#include <stdio.h>
#include <stdlib.h>

int main() {
    int n, i, *arr, sum = 0;
    printf("Enter number of elements: ");
    scanf("%d", &n);

    arr = (int*) malloc(n * sizeof(int));
    if (arr == NULL) {
        printf("Memory allocation failed\n");
        return 1;
    }

    printf("Enter %d integers: ", n);
    for (i = 0; i < n; i++) {
        scanf("%d", &arr[i]);
        sum += arr[i];
    }
    printf("Sum = %d\n", sum);

    free(arr);
    arr = NULL;
    return 0;
}
Sample Output
Enter number of elements: 4
Enter 4 integers: 10 20 30 40
Sum = 100

5.2 File Handling

Header: <stdio.h>. File pointer: FILE *fp;

Modes: "r", "w", "a", "r+", "w+", "a+" (+ "b" for binary)

Key functions: fopen, fclose, fprintf/fscanf, fgetc/fputc, fgets/fputs, fread/fwrite, fseek, ftell, rewind

#include <stdio.h>
int main() {
    FILE *fp;
    char str[100];

    /* Write */
    fp = fopen("data.txt", "w");
    if (fp == NULL) { printf("Cannot open file\n"); return 1; }
    fprintf(fp, "Hello File Handling\n");
    fprintf(fp, "Line number two\n");
    fclose(fp);

    /* Read */
    fp = fopen("data.txt", "r");
    while (fgets(str, sizeof(str), fp) != NULL)
        printf("%s", str);
    fclose(fp);
    return 0;
}
Output
Hello File Handling
Line number two
