UNIT I — Set Theory, Relations & Functions

1. Set Theory — Introduction

A set is a well-defined collection of distinct objects. The objects are called elements or members of the set. We write sets using curly braces { }.

Notation: If a is an element of set A, we write a ∈ A. If a is not in A, we write a ∉ A.

Ways to represent a set:

  1. Roster method (listing): A = {1, 2, 3, 4}
  2. Set-builder method: A = {x | x is a natural number and x ≤ 4}
Example — Basic sets

A = {a, e, i, o, u} → set of vowels

B = {x | x is an even number between 1 and 10} = {2, 4, 6, 8}

Empty set (null set): ∅ or { } — a set with no elements

Universal set U: the set that contains all elements under consideration

2. Size of Sets and Cardinals

The cardinality (or size) of a set A is the number of elements in A. It is denoted by |A| or n(A).

  • Finite set: has a finite number of elements (e.g., |A| = 5)
  • Infinite set: has infinitely many elements (e.g., set of natural numbers ℕ)
  • Two sets have the same cardinality if there is a one-to-one correspondence (bijection) between them.
Example — Cardinality

A = {1, 2, 3} → |A| = 3

B = {a, b, c, d} → |B| = 4

Power set of A: P(A) = {∅, {1}, {2}, {3}, {1,2}, {1,3}, {2,3}, {1,2,3}} → |P(A)| = 2³ = 8

Question

If A = {1, 2, 3, 4} and B = {3, 4, 5}, find |A|, |B| and |A ∪ B|.

Solution: |A| = 4, |B| = 3. A ∪ B = {1, 2, 3, 4, 5}, so |A ∪ B| = 5.
Note: |A ∪ B| = |A| + |B| − |A ∩ B| = 4 + 3 − 2 = 5.

3. Venn Diagrams

A Venn diagram is a picture that shows relationships between sets using circles (or other shapes) inside a rectangle (the universal set).

  • Overlapping circles show common elements (intersection).
  • Non-overlapping circles show disjoint sets.
  • Shaded regions help visualize union, intersection, complement, difference, etc.

4. Operations on Sets

  • Union (A ∪ B): Elements that are in A or B or both.
  • Intersection (A ∩ B): Elements that are in both A and B.
  • Difference (A − B or A \ B): Elements in A but not in B.
  • Complement (A′ or Ac): Elements in the universal set U that are not in A.
  • Symmetric Difference (A ∆ B): Elements in A or B but not in both. A ∆ B = (A − B) ∪ (B − A).
Example — Set operations

Let U = {1,2,3,4,5,6,7,8}, A = {1,2,3,4}, B = {3,4,5,6}

A ∪ B = {1,2,3,4,5,6}
A ∩ B = {3,4}
A − B = {1,2}
B − A = {5,6}
A′ = {5,6,7,8}
A ∆ B = {1,2,5,6}

Question

Using the sets above, verify |A ∪ B| = |A| + |B| − |A ∩ B|.

Solution: |A| = 4, |B| = 4, |A ∩ B| = 2, |A ∪ B| = 6. Right side: 4 + 4 − 2 = 6. Verified.

5. Multisets

A multiset (or bag) is like a set but allows repeated elements. The number of times an element appears is its multiplicity.

Example — Multiset

M = {a, a, b, c, c, c} — a appears twice, b once, c three times.

We can write M = {2·a, 1·b, 3·c}.

Cardinality of a multiset counts with multiplicity: |M| = 2 + 1 + 3 = 6.

6. Ordered Pairs

An ordered pair (a, b) is a pair of elements where order matters. (a, b) ≠ (b, a) unless a = b.

The Cartesian product A × B = {(a, b) | a ∈ A, b ∈ B}.

Example — Cartesian product

A = {1, 2}, B = {x, y}

A × B = {(1,x), (1,y), (2,x), (2,y)}

|A × B| = |A| × |B| = 2 × 2 = 4

7. Set Identities (Laws)

These are rules that always hold for any sets A, B, C (and universal set U):

  • Idempotent: A ∪ A = A, A ∩ A = A
  • Commutative: A ∪ B = B ∪ A, A ∩ B = B ∩ A
  • Associative: (A ∪ B) ∪ C = A ∪ (B ∪ C), same for ∩
  • Distributive: A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C), A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
  • De Morgan’s: (A ∪ B)′ = A′ ∩ B′, (A ∩ B)′ = A′ ∪ B′
  • Identity: A ∪ ∅ = A, A ∩ U = A
  • Complement: A ∪ A′ = U, A ∩ A′ = ∅
  • Absorption: A ∪ (A ∩ B) = A, A ∩ (A ∪ B) = A
Question

Prove using set identities: simplify (A ∪ B)′ ∪ B′.

Solution: By De Morgan: (A ∪ B)′ = A′ ∩ B′. Then (A′ ∩ B′) ∪ B′. By absorption: B′ ∪ (A′ ∩ B′) = B′. (The expression simplifies to B′.)

8. Relations — Definition

A relation R from set A to set B is any subset of the Cartesian product A × B. If (a, b) ∈ R we say “a is related to b” and write a R b.

When A = B, R is a relation on A (subset of A × A).

Example — Relation

A = {1, 2, 3}. Let R = {(1,1), (1,2), (2,2), (3,1), (3,3)}

Then 1 R 1, 1 R 2, 2 R 2, 3 R 1, 3 R 3 are true.
2 is not related to 1 because (2,1) ∉ R.

9. Operations on Relations

  • Union: R ∪ S = {(a,b) | (a,b) ∈ R or (a,b) ∈ S}
  • Intersection: R ∩ S = {(a,b) | (a,b) ∈ R and (a,b) ∈ S}
  • Complement: R′ = (A × B) − R
  • Inverse: R−1 = {(b,a) | (a,b) ∈ R}

10. Composite Relations

If R is a relation from A to B and S is a relation from B to C, the composition S ∘ R (or R; S) is a relation from A to C defined by:
(a, c) ∈ S ∘ R if and only if there exists b ∈ B such that (a, b) ∈ R and (b, c) ∈ S.

Example — Composition

A = {1,2}, B = {a,b}, C = {x,y}

R = {(1,a), (2,b)}, S = {(a,x), (b,y), (a,y)}

S ∘ R = {(1,x), (1,y), (2,y)}

11. Properties of Relations (on a set A)

  • Reflexive: For every a ∈ A, (a,a) ∈ R.
  • Symmetric: If (a,b) ∈ R then (b,a) ∈ R.
  • Antisymmetric: If (a,b) ∈ R and (b,a) ∈ R then a = b.
  • Transitive: If (a,b) ∈ R and (b,c) ∈ R then (a,c) ∈ R.
  • Equivalence relation: Reflexive + Symmetric + Transitive.
  • Partial order relation: Reflexive + Antisymmetric + Transitive.
Example — Checking properties

A = {1,2,3}, R = {(1,1),(2,2),(3,3),(1,2),(2,3),(1,3)}

  • Reflexive: Yes (all diagonals present).
  • Symmetric: No (1,2 is present but 2,1 is not).
  • Antisymmetric: Yes (no pair and its reverse both present except equals).
  • Transitive: Yes (1R2 and 2R3 ⇒ 1R3, which is present).

This is a partial order (≤ on numbers).

Question

Is the relation “divides” on the set of positive integers an equivalence relation? Why?

Solution: Reflexive: a divides a (yes). Symmetric: if a divides b then b divides a? Only when a = b. Not symmetric in general (2 divides 4 but 4 does not divide 2). Hence not equivalence. It is a partial order (reflexive, antisymmetric, transitive).

12–13. Equality of Relations & Partial Order

Two relations R and S are equal if they contain exactly the same ordered pairs.

A relation ≤ on a set A is a partial order if it is reflexive, antisymmetric and transitive. The pair (A, ≤) is called a partially ordered set or poset. Examples: (ℕ, ≤), (power set of S ordered by ⊆), (positive integers ordered by “divides”).

14. Functions — Definition

A function f from A to B (written f: A → B) is a relation from A to B such that every element of A is related to exactly one element of B. A is the domain, B is the codomain. If f(a) = b we say b is the image of a.

15. Classification of Functions

  • Injective (one-one): f(a₁) = f(a₂) ⇒ a₁ = a₂. Different inputs give different outputs.
  • Surjective (onto): Every element of B is the image of at least one element of A. Range = codomain.
  • Bijective: Both injective and surjective. (One-to-one correspondence)
  • Constant: Same output for every input.
  • Identity: f(a) = a for all a (domain = codomain).
Example — Types of functions

f: ℕ → ℕ, f(x) = 2x → injective but not surjective (odd numbers missed).

f: ℝ → ℝ, f(x) = x³ → bijective.

f: ℝ → ℝ, f(x) = x² → neither injective nor surjective (onto non-negative reals only).

f: {1,2,3} → {a,b}, f(1)=a, f(2)=a, f(3)=b → surjective but not injective.

16. Operations on Functions

  • Composition: (g ∘ f)(x) = g(f(x)). Domain of g must contain the range of f.
  • Addition / Multiplication (when codomain is numbers): (f + g)(x) = f(x) + g(x), (f·g)(x) = f(x)·g(x).
  • Inverse: Only bijective functions have inverse functions. f−1(f(x)) = x and f(f−1(y)) = y.

17. Recursively Defined Functions

A function is defined recursively by giving a base case and a rule that defines later values from earlier ones.

Example — Factorial and Fibonacci

Factorial: n! = 1 if n = 0; n! = n · (n−1)! if n > 0.

Fibonacci: F(0)=0, F(1)=1; F(n) = F(n−1) + F(n−2) for n ≥ 2.

F(2)=1, F(3)=2, F(4)=3, F(5)=5, F(6)=8, …

Question

Compute F(7) using the recursive definition of Fibonacci.

Solution: F(5)=5, F(6)=8 ⇒ F(7) = F(6)+F(5) = 8+5 = 13.
UNIT II — Posets, Hasse Diagrams, Lattices & Boolean Algebra

1. Partial Ordered Sets (Posets)

A poset is a set P together with a partial order ≤ on P. We write (P, ≤).

Elements a and b are comparable if a ≤ b or b ≤ a; otherwise they are incomparable.

Special elements:

  • Maximal element: nothing strictly above it.
  • Minimal element: nothing strictly below it.
  • Greatest element (maximum): ≥ every other element.
  • Least element (minimum): ≤ every other element.
  • Upper bound of a subset S: an element ≥ all members of S.
  • Least upper bound (supremum, join): the least of the upper bounds.
  • Greatest lower bound (infimum, meet): the greatest of the lower bounds.

2. Combination of Partial Ordered Sets

  • Direct product: A × B ordered componentwise: (a₁,b₁) ≤ (a₂,b₂) iff a₁ ≤A a₂ and b₁ ≤B b₂.
  • Lexicographic order: compare first components; if equal, compare second, etc.

3. Hasse Diagram

A Hasse diagram is a simplified picture of a finite poset:

  • Draw elements as points/vertices.
  • Draw an edge upward from a to b if a < b and there is no element strictly between them (cover relation).
  • Omit arrows and transitive edges; direction is understood to be upward.
Example — Hasse diagram of divisors of 12

Set D = {1, 2, 3, 4, 6, 12} ordered by “divides”.

1 is at the bottom; 12 is at the top.

Edges: 1—2, 1—3, 2—4, 2—6, 3—6, 4—12, 6—12.

No direct edge 1—4 because 2 is between them.

Question

Draw (mentally) the Hasse diagram of the power set of {a,b} ordered by inclusion. What are the maximal/minimal elements?

Solution: Elements: ∅, {a}, {b}, {a,b}. ∅ at bottom, {a,b} at top. Edges: ∅—{a}, ∅—{b}, {a}—{a,b}, {b}—{a,b}. Minimal element: ∅. Maximal element: {a,b}. They are also the least and greatest elements.

4. Lattices — Introduction

A lattice is a poset in which every two elements have a least upper bound (join, ∨) and a greatest lower bound (meet, ∧).

Examples: (ℤ, min, max), power set of any set with ∪ and ∩, divisors of n with lcm and gcd.

5. Properties of Lattices

  • Bounded lattice: has a greatest element 1 (top) and a least element 0 (bottom).
  • Complemented lattice: bounded lattice where every element a has a complement a′ such that a ∨ a′ = 1 and a ∧ a′ = 0.
  • Modular lattice: if a ≤ c then a ∨ (b ∧ c) = (a ∨ b) ∧ c.
  • Distributive lattice: joins distribute over meets and vice versa.
  • Complete lattice: every subset (not just pairs) has a supremum and an infimum.
Example — Lattice examples

Power set of {1,2,3} with ⊆ is a bounded, complemented, distributive, complete lattice.

0 = ∅, 1 = {1,2,3}. Complement of {1} is {2,3}.

The diamond lattice M3 (five elements) is modular but not distributive.

6. Boolean Algebra — Introduction

A Boolean algebra is a bounded distributive complemented lattice. Equivalently, a set B with operations +, ·, ′ (or ∨, ∧, ¬) and constants 0, 1 satisfying the Boolean axioms.

7. Axioms and Theorems of Boolean Algebra

Axioms (Huntington):

  1. Commutative: a + b = b + a, a · b = b · a
  2. Distributive: a + (b · c) = (a + b) · (a + c), a · (b + c) = (a · b) + (a · c)
  3. Identity: a + 0 = a, a · 1 = a
  4. Complement: a + a′ = 1, a · a′ = 0

Useful theorems:

  • Idempotent: a + a = a, a · a = a
  • Absorption: a + (a · b) = a, a · (a + b) = a
  • De Morgan: (a + b)′ = a′ · b′, (a · b)′ = a′ + b′
  • Involution: (a′)′ = a
  • 0′ = 1, 1′ = 0

8. Boolean Functions & Simplification

A Boolean function of n variables is an expression using the variables, 0, 1 and the operations +, ·, ′. Simplification reduces the number of terms/literals (cheaper circuit).

Algebraic method: use the theorems above (factor, absorb, De Morgan, etc.).

Example — Simplify F = A·B + A·B′ + A′·B

F = A·(B + B′) + A′·B = A·1 + A′·B = A + A′·B

F = (A + A′)·(A + B) = 1·(A + B) = A + B (by distributive)

So F simplifies to A + B.

9. Karnaugh Maps (K-maps)

A Karnaugh map is a grid that helps minimize Boolean functions visually. Adjacent cells differ by only one variable. Group powers-of-two of 1-cells to eliminate variables.

For 2 variables: 2×2 grid. For 3 variables: 2×4. For 4 variables: 4×4. Gray-code labeling ensures only one bit changes between neighbors (including wrap-around).

Question

Minimize F(A,B,C) = Σ(0,1,2,5,6,7) using a 3-variable K-map idea.

Solution: Cells 0,1,2,5,6,7 are 1. Large groups: (0,1,2,…) and (5,7,6,…). One minimal expression is F = A′·B′ + B·C′ + A·C (or equivalent).

10. Logic Gates

  • AND gate: output 1 only if all inputs are 1 (·).
  • OR gate: output 1 if at least one input is 1 (+).
  • NOT gate (inverter): flips 0↔1 (′).
  • NAND = NOT-AND; NOR = NOT-OR; XOR = exclusive OR; XNOR = exclusive NOR.

Any Boolean function can be realized with AND, OR, NOT (or with only NAND, or only NOR).

UNIT III — Propositional Logic & Predicate Logic

1. Propositions

A proposition is a declarative sentence that is either true (T) or false (F), but not both. It has a definite truth value.

Example — Propositions vs non-propositions

“2 + 2 = 4” — proposition (true).

“New Delhi is the capital of India” — proposition (true).

“x + 1 = 5” — not a proposition (depends on x).

“What is your name?” — not a proposition (question).

“Close the door!” — not a proposition (command).

2. Truth Tables & Connectives

  • Negation ¬P (not P): opposite truth value.
  • Conjunction P ∧ Q (and): true only when both true.
  • Disjunction P ∨ Q (or): true when at least one is true.
  • Implication P → Q (if P then Q): false only when P true and Q false.
  • Biconditional P ↔ Q (iff): true when both have same truth value.

3. Tautology, Contradiction, Contingency

  • Tautology: always true (e.g., P ∨ ¬P).
  • Contradiction: always false (e.g., P ∧ ¬P).
  • Contingency: sometimes true, sometimes false.
Example

Check if (P → Q) ↔ (¬Q → ¬P) is a tautology.

This is the law of contrapositive. Both sides have the same truth table, so the biconditional is always true → tautology.

4. Algebra of Propositions

Same laws as Boolean algebra / set theory: commutative, associative, distributive, De Morgan, identity, complement, idempotent, absorption, etc.

P ∨ ¬P ≡ T, P ∧ ¬P ≡ F, ¬(¬P) ≡ P, ¬(P ∨ Q) ≡ ¬P ∧ ¬Q, …

5. Theory of Inference & Natural Deduction

Rules that let us derive new true statements from known true statements:

  • Modus Ponens: From P and P → Q, infer Q.
  • Modus Tollens: From ¬Q and P → Q, infer ¬P.
  • Hypothetical Syllogism: From P → Q and Q → R, infer P → R.
  • Disjunctive Syllogism: From P ∨ Q and ¬P, infer Q.
  • Addition: From P, infer P ∨ Q.
  • Simplification: From P ∧ Q, infer P.
  • Conjunction: From P and Q, infer P ∧ Q.
  • Resolution: From P ∨ Q and ¬P ∨ R, infer Q ∨ R.
Question

Given: (1) P → Q, (2) Q → R, (3) P. Prove R.

Solution: From (1) and (3) by Modus Ponens: Q. From Q and (2) by Modus Ponens: R. Done.

6–8. Predicate Logic & Quantifiers

A predicate is a statement containing variables; it becomes a proposition when variables are given values or when quantifiers are applied. Example: P(x) = “x is even”.

  • Universal quantifier ∀ (“for all”): ∀x P(x) means P(x) is true for every x in the domain.
  • Existential quantifier ∃ (“there exists”): ∃x P(x) means there is at least one x such that P(x) is true.

Negation: ¬∀x P(x) ≡ ∃x ¬P(x), ¬∃x P(x) ≡ ∀x ¬P(x).

Example — Quantifiers

Domain = natural numbers. ∀x (x ≥ 0) is true. ∃x (x < 0) is false.

∀x ∃y (y = x + 1) is true (successor always exists).

∃y ∀x (y = x + 1) is false (no single y works for all x).

9. Inference Theory of Predicate Logic

  • Universal Instantiation (UI): From ∀x P(x) infer P(c) for any constant c.
  • Universal Generalization (UG): From P(c) (c arbitrary) infer ∀x P(x).
  • Existential Instantiation (EI): From ∃x P(x) infer P(c) for a new constant c.
  • Existential Generalization (EG): From P(c) infer ∃x P(x).
Question

Given: ∀x (Man(x) → Mortal(x)) and Man(Socrates). Prove Mortal(Socrates).

Solution: By UI: Man(Socrates) → Mortal(Socrates). By Modus Ponens with Man(Socrates): Mortal(Socrates).
UNIT IV — Algebraic Structures, Rings & Fields

1. Introduction to Algebraic Structures

An algebraic structure is a set together with one or more binary operations that satisfy certain axioms. Examples: (ℤ, +), (ℤ, +, ·), (power set, ∪, ∩).

2. Types of Algebraic Structures

  • Semigroup: Set S with associative binary operation ∗. (a ∗ b) ∗ c = a ∗ (b ∗ c).
  • Monoid: Semigroup with an identity element e (a ∗ e = e ∗ a = a).
  • Group: Monoid in which every element has an inverse (a ∗ a−1 = a−1 ∗ a = e).
  • Abelian (commutative) group: Group whose operation is also commutative (a ∗ b = b ∗ a).
Example

(ℕ, +) is a semigroup (actually monoid with 0) but not a group (no inverses for positive numbers).

(ℤ, +) is an abelian group. Identity 0, inverse of n is −n.

(ℝ \ {0}, ·) is an abelian group. Identity 1, inverse of x is 1/x.

Set of 2×2 invertible matrices with multiplication is a non-abelian group (GL(2)).

3. Properties of Groups

  • Identity is unique.
  • Inverse of each element is unique.
  • (a−1)−1 = a.
  • (a ∗ b)−1 = b−1 ∗ a−1.
  • Cancellation: a ∗ b = a ∗ c ⇒ b = c (left and right).

4. Subgroup

A non-empty subset H of a group G is a subgroup if H itself is a group under the same operation. Equivalent test: for all a, b ∈ H, a ∗ b−1 ∈ H.

5. Cyclic Group

A group G is cyclic if there exists an element g (a generator) such that every element of G is a power of g: G = {gk | k ∈ ℤ}. Written G = ⟨g⟩. All cyclic groups are abelian.

Example — Cyclic groups

(ℤ, +) is infinite cyclic, generated by 1 (or by −1).

ℤn (integers mod n under addition) is cyclic of order n, generated by 1.

The multiplicative group {1, −1, i, −i} is cyclic of order 4, generated by i.

6. Cosets

Let H be a subgroup of G and a ∈ G. The left coset of H containing a is aH = {a ∗ h | h ∈ H}. Right coset is Ha. Cosets partition the group. Lagrange’s theorem: |G| = |H| · (number of distinct cosets).

7. Permutation Groups

A permutation of a set is a bijective function from the set to itself. The set of all permutations of {1,2,…,n} forms the symmetric group Sn under composition. Subgroups of Sn are permutation groups. Sn has order n!.

8. Homomorphism and Isomorphism of Groups

A homomorphism φ: G → H is a map that preserves the operation: φ(a ∗ b) = φ(a) ∗ φ(b).

An isomorphism is a bijective homomorphism. If an isomorphism exists, G and H are essentially the same group (isomorphic).

Example — Homomorphism

φ: (ℤ, +) → (ℤn, +), φ(k) = k mod n is a surjective homomorphism (kernel = nℤ).

The map x ↦ ex from (ℝ, +) to (ℝ>0, ·) is an isomorphism.

9. Rings and Fields

Ring: A set R with two operations + and · such that (R, +) is an abelian group, · is associative and distributive over +.

If · is commutative we have a commutative ring; if there is a multiplicative identity 1 we have a ring with unity.

Field: A commutative ring with unity in which every non-zero element has a multiplicative inverse. (Both (F, +) and (F \ {0}, ·) are abelian groups.)

Example — Rings and Fields

ℤ is a commutative ring with unity, not a field (2 has no inverse in ℤ).

ℚ, ℝ, ℂ are fields.

ℤn is a field if and only if n is prime.

Set of 2×2 matrices is a non-commutative ring with unity.

Question

Why is ℤ6 not a field?

Solution: 6 is not prime. 2 and 3 are zero-divisors: 2·3 ≡ 0 (mod 6), and neither has a multiplicative inverse.
UNIT V — Natural Numbers, Recurrence Relations & Combinatorics

1. Natural Numbers & Peano’s Axioms

Peano’s axioms characterize the natural numbers ℕ = {0, 1, 2, …} (or sometimes starting from 1):

  1. 0 is a natural number.
  2. Every natural number n has a unique successor S(n) (think n+1).
  3. 0 is not the successor of any natural number.
  4. Different numbers have different successors (S is injective).
  5. Induction axiom: If a set contains 0 and is closed under successor, it contains all natural numbers.

2. Mathematical Induction

Ordinary induction: To prove P(n) for all n ≥ n0:

  1. Base case: Prove P(n0).
  2. Inductive step: Assume P(k) (inductive hypothesis) and prove P(k+1).

Strong induction: Assume P(m) for all m with n0 ≤ m ≤ k, and prove P(k+1).

Example — Prove 1 + 2 + … + n = n(n+1)/2 by induction

Base: n=1 → 1 = 1·2/2 = 1. True.

Assume true for k: 1+…+k = k(k+1)/2.

For k+1: 1+…+k+(k+1) = k(k+1)/2 + (k+1) = (k+1)(k/2 + 1) = (k+1)(k+2)/2.

True for k+1. By induction, true for all n ≥ 1.

Question

Prove by induction that 2n > n for all natural numbers n ≥ 1.

Solution: Base n=1: 2 > 1 true. Assume 2k > k. Then 2k+1 = 2·2k > 2k ≥ k+1 (since k ≥ 1). True for k+1. Done.

3. Recurrence Relations & Generating Functions

A recurrence relation defines a sequence by giving initial terms and a rule for later terms from earlier ones. Example: an = 3 an−1 + 2, with a0 = 1.

A generating function for a sequence (an) is the power series G(x) = Σ an xn. It turns recurrence relations into algebraic equations.

4. Linear Recurrence Relations

With constant coefficients: an + c1 an−1 + … + ck an−k = f(n).

Homogeneous (f=0): characteristic equation rk + c1 rk−1 + … + ck = 0. General solution is linear combination of rn (or nj rn for multiple roots).

Non-homogeneous: find particular solution + homogeneous solution.

Example — Solve an = 5 an−1 − 6 an−2, a0=0, a1=1

Characteristic equation: r² − 5r + 6 = 0 → (r−2)(r−3)=0 → r=2,3.

General solution: an = A · 2n + B · 3n.

a0=0 ⇒ A + B = 0. a1=1 ⇒ 2A + 3B = 1.

From A = −B: −2B + 3B = 1 ⇒ B=1, A=−1.

an = −2n + 3n.

Question

Find a closed form for an = 2 an−1 with a0 = 3.

Solution: Unfold: an = 2 an−1 = 2² an−2 = … = 2n a0 = 3 · 2n.

5. Combinatorics — Introduction & Counting Techniques

  • Sum rule: If a task can be done in m ways or n ways (disjoint), total = m + n.
  • Product rule: If a task has k successive steps with ni choices each, total = n1 · n2 · … · nk.
  • Permutations: P(n,r) = n! / (n−r)! (ordered selections).
  • Combinations: C(n,r) = n! / (r!(n−r)!) (unordered selections).
  • Binomial theorem: (x+y)n = Σ C(n,k) xn−k yk.
Example — Counting

Number of ways to choose 3 students from 10: C(10,3) = 120.

Number of 3-letter words from {A,B,C,D,E} with repetition: 5³ = 125.

Without repetition: P(5,3) = 5·4·3 = 60.

6. Pigeonhole Principle

Basic: If n+1 pigeons are put into n holes, at least one hole contains more than one pigeon.

Generalized: If N objects are placed into k boxes, then at least one box contains at least ⌈N/k⌉ objects.

Question

How many students must be in a class to guarantee that at least two have birthdays in the same month?

Solution: 12 months (holes). To guarantee two in the same month: 12 + 1 = 13 students (pigeons).

7. Polya’s Counting Theorem (Introduction)

Polya’s enumeration theorem counts distinct objects under group actions (symmetries). It uses the cycle index of a permutation group. Classic application: counting distinct necklaces that can be rotated/flipped, or distinct colorings of a cube’s faces up to rotation.

Simple idea: average the number of colorings fixed by each symmetry. For a cyclic group of order n acting on n beads with c colors, the number of distinct necklaces (rotations only) is (1/n) Σd|n φ(d) cn/d (where φ is Euler’s totient).

Example — Necklace with 3 beads, 2 colors (rotations only)

n=3, c=2. Divisors of 3: 1 and 3. φ(1)=1, φ(3)=2.

Number = (1/3)[φ(1)·2³ + φ(3)·2¹] = (1/3)(1·8 + 2·2) = (8+4)/3 = 4.

The four: all color A, all color B, two A one B, two B one A.
