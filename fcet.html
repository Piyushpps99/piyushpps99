UNIT I : Introduction to Computer

1.1 Definition of Computer

A computer is an electronic machine that takes data (input), processes it according to instructions (program), and gives useful results (output). It can store large amounts of data and work very fast with high accuracy.

Key Point: Computer = Input + Process + Output + Storage. It follows the IPO cycle (Input-Process-Output).

A computer has two main parts: Hardware (physical parts you can touch) and Software (programs and instructions that tell the hardware what to do).

1.2 Computer Hardware Components

Hardware means all the physical parts of a computer. You can see and touch them. Hardware is divided into four main groups: Input devices, Output devices, Central Processing Unit (CPU), and Memory (Primary and Secondary).

1.2.3 Central Processing Unit (CPU)

The CPU is called the 'brain' of the computer. It performs all calculations and controls all other parts. It has three main parts:

  • Arithmetic Logic Unit (ALU): Does all math (add, subtract, multiply, divide) and logical decisions (compare, AND, OR).
  • Control Unit (CU): Controls the flow of data and instructions. It tells other parts what to do and when.
  • Registers: Very small and very fast memory locations inside the CPU that hold data temporarily while processing.
Key Point: CPU speed is measured in GHz (gigahertz). Higher GHz usually means faster processing. Modern CPUs have multiple cores (multi-core) so they can do many tasks at the same time.

1.2.4 Memory – Primary and Secondary

Primary Memory (Main Memory) – Fast but usually temporary (data is lost when power is off, except ROM).

  • RAM (Random Access Memory): Temporary memory. Programs and data currently in use stay here. More RAM = better multitasking.
  • ROM (Read Only Memory): Permanent memory. Stores the basic startup instructions (BIOS/UEFI).
  • Cache Memory: Extremely fast memory inside or near the CPU for frequently used data.

Secondary Memory (Storage) – Permanent storage. Data stays even when the computer is turned off.

  • Hard Disk Drive (HDD): Spinning magnetic disks. Large capacity, cheaper, slower.
  • Solid State Drive (SSD): Flash memory chips. Much faster, more expensive per GB.
  • USB Flash Drive / Pen Drive, Optical Disks, Memory Cards

1.3 Computer Software Components

Software is a set of programs and instructions that tell the hardware what to do. Without software, hardware is useless. Software is divided into two main types:

1.3.1 System Software

  • Operating System (OS): Windows, macOS, Linux, Android, iOS – manages files, memory, devices and user interface.
  • Device Drivers: Allow the OS to communicate with hardware devices.
  • Utility Programs: Antivirus, disk cleanup, backup tools, file compressors.
  • Firmware: Software permanently stored on hardware chips (like BIOS).

1.3.2 Application Software

  • Word Processors (MS Word, Google Docs)
  • Spreadsheets (MS Excel, Google Sheets)
  • Presentation Software (PowerPoint, Google Slides)
  • Web Browsers (Chrome, Firefox, Edge)
  • Media Players, Games, Design tools, Accounting software, Databases
Key Point: System software makes the computer work. Application software helps users do useful work.

1.4 Computer Languages

Computers understand only machine language (0s and 1s). Humans write programs in higher-level languages.

  • Machine Language: Only 0s and 1s. Directly understood by CPU.
  • Assembly Language: Uses short codes (mnemonics) like ADD, MOV. Needs an Assembler.
  • High-Level Languages: Python, Java, C++, JavaScript. Need Compiler or Interpreter.

1.5 Problem Solving Concepts & Algorithms

An Algorithm is a clear, step-by-step set of instructions to solve a problem or complete a task. It is written in simple language (or pseudo-code) before writing actual program code.

Characteristics of a Good Algorithm

  • Input: Takes zero or more inputs
  • Output: Produces at least one output
  • Definiteness: Each step must be clear and unambiguous
  • Finiteness: Must finish after a limited number of steps
  • Effectiveness: Every step must be basic and possible to perform
  • Generality: Should work for a class of problems

Conditions in Pseudo-code

IF age >= 18 THEN
    Print "You can vote"
ELSE
    Print "You cannot vote"
ENDIF

Loops in Pseudo-code

FOR i = 1 TO 5 DO
    Print i
ENDFOR
SET count = 1
WHILE count <= 5 DO
    Print count
    count = count + 1
ENDWHILE
Always make sure loops have a clear stopping condition, otherwise the program may run forever.

UNIT II : Operating System & Computer Network

2.1 Operating System

An Operating System (OS) is the most important system software. It acts as a bridge between the user and the computer hardware. It manages all hardware resources and provides services so that application programs can run smoothly.

Windows 11 macOS Linux Android / iOS

Functions of Operating System

  • Process Management – Creates, schedules and terminates processes
  • Memory Management – Allocates and frees RAM
  • File Management – Organizes files and folders, controls access
  • Device Management – Controls I/O devices through drivers
  • Security & Protection – Passwords, permissions
  • User Interface – CLI or GUI
  • Networking – Manages network connections

Types of Operating Systems

Batch OS

Jobs collected in batches and processed one after another.

Time-Sharing / Multitasking

Multiple users/programs share CPU with time slices.

Real-Time OS (RTOS)

Responds within strict time limits (medical, aircraft).

Distributed & Network OS

Manages group of computers as one system.

CLI vs GUI

Command Line Interface: Fast for experts, low resource usage, powerful automation. Hard for beginners.

Graphical User Interface: Easy to learn, visual, user-friendly. Uses more memory and CPU.

2.2 Computer Network

A Computer Network is a group of two or more computers connected together so they can share data, resources and communicate.

Types of Networks

TypeFull FormArea CoveredExample
LANLocal Area NetworkSmall area (home, office)Home Wi-Fi, office network
MANMetropolitan Area NetworkCity or large campusCable TV, city Wi-Fi
WANWide Area NetworkCountry / WorldInternet, bank networks

Network Topologies

  • Bus Topology – Single central cable. Simple but single point of failure.
  • Star Topology – All devices connected to central hub/switch. Most common.
  • Ring Topology – Closed loop. Failure of one device can affect whole network.
  • Mesh Topology – Every device connected to every other. Highly reliable but expensive.
  • Tree & Hybrid Topology – Combinations of the above.

UNIT III : Internet & Internet of Things

3.1 Internet

The Internet is a global network of millions of computers and devices connected together. It is often called the 'network of networks'.

Architecture & Functioning

  • Data is broken into small packets that travel independently.
  • IP gives every device a unique address.
  • TCP ensures reliable delivery of packets.
  • DNS converts website names into IP addresses.

Basic Services

  • WWW – World Wide Web (websites & pages)
  • FTP – File Transfer Protocol
  • E-mail – SMTP, POP3/IMAP
  • Search Engines – Google, Bing, DuckDuckGo
  • Web Browsers – Chrome, Firefox, Edge, Safari

3.2 Internet of Things (IoT)

IoT means connecting everyday physical objects to the internet so they can collect data, share data, and be controlled remotely.

Examples: Smart lights, smart thermostats, fitness bands, smart refrigerators, connected cars.

UNIT IV : Blockchain, Cryptocurrencies & Cloud Computing

4.1 Blockchain

Blockchain is a special kind of database (distributed ledger) that stores information in blocks linked together using cryptography. Once data is recorded, it is very hard to change. It is decentralized.

Decentralization

No central authority. Data stored on many nodes.

Immutability

Extremely difficult to change past records.

Transparency

Transactions visible to participants.

Security

Cryptographic hashing + digital signatures.

Application Areas

  • Cryptocurrencies, Supply chain tracking, Digital identity
  • Voting systems, Smart contracts, Healthcare records
  • Banking and cross-border payments

4.2 Cryptocurrencies

Digital or virtual currency that uses cryptography for security. Usually works on blockchain. Not issued by any central bank. Bitcoin was the first.

Use cases: Digital payments, Investment / Store of value, Remittances, DeFi, NFTs, Micropayments & gaming.

Note: Cryptocurrencies are highly volatile and involve risk. Regulations differ by country.

4.3 Cloud Computing

Delivering computing services (servers, storage, databases, software) over the internet. You rent them and pay only for what you use.

Main Benefits

  • Cost saving (pay-as-you-go)
  • Scalability & Accessibility
  • Reliability & Automatic updates
  • Professional security

Major Cloud Providers

Amazon Web Services (AWS)

EC2, S3, Lambda, RDS, CloudFront. Largest provider.

Google Cloud Platform

Strong in data analytics & ML. BigQuery, Kubernetes.

Microsoft Azure

Strong integration with Microsoft products. Popular with enterprises.

IBM Cloud

Focus on enterprise, hybrid cloud and AI (Watson).

Service models: IaaS (Infrastructure), PaaS (Platform), SaaS (Software)

UNIT V : Emerging Technologies

5.1 Augmented Reality (AR)

Overlays digital information (images, text, 3D models) onto the real world through a camera or special glasses.

Applications: Pokémon GO, IKEA furniture apps, navigation arrows, medical training, industrial maintenance, interactive education.

5.2 Virtual Reality (VR)

Creates a completely computer-generated environment that replaces the real world. Users wear a VR headset.

Applications: Gaming, virtual tourism, architectural walkthroughs, medical surgery training, military simulation, therapy, metaverse.

5.3 Grid Computing

Connects many computers (often in different locations) to work together on large computational problems – creating a virtual supercomputer.

Applications: Climate modeling, particle physics (CERN), drug discovery, weather forecasting, financial risk analysis.

5.4 Green Computing

Designing, using and disposing of computers in an environmentally friendly way to reduce energy use and environmental impact.

Practices: Energy-efficient hardware, virtualization, power management, recycling e-waste, renewable energy for data centers, paperless offices.

5.5 Big Data Analytics

Examining extremely large and complex data sets to find patterns, trends and insights.

The 5 Vs: Volume • Velocity • Variety • Veracity • Value

Applications: Recommendation systems (Netflix, Amazon), fraud detection, healthcare diagnosis, traffic management, targeted marketing.

5.6 Quantum Computing

Uses principles of quantum mechanics (superposition and entanglement). Instead of classical bits (0 or 1), it uses qubits that can be 0, 1, or both at the same time.

Potential applications: Cryptography, drug & material discovery, financial modeling, optimization problems, AI research.

5.7 Brain Computer Interface (BCI)

Creates a direct communication path between the human brain and an external device. Reads brain signals and converts them into commands.

Applications: Helping paralyzed patients control wheelchairs or prosthetic limbs, communication for locked-in patients, gaming, brain research.
